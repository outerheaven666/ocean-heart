# 海洋之心 · 海水玩家社区

中国海水观赏玩家的一站式家园 —— **权威生物资料库 × 玩家交流社区 × 合规商家服务**。

依据 `plan.md` 与 `海洋之心-执行方案.md` 实施的 Stage 3–5 交付物:可部署上线的全栈 Web 应用。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui(`app/`) |
| 后端 | Hono + tRPC v11 + Drizzle ORM(`server/`) |
| 数据库 | 默认 SQLite(better-sqlite3,`server/data/ocean-heart.db`,启动自动建表+灌种子数据)。schema 与方案 10 表设计一致,切换 MySQL 仅需更换 Drizzle 驱动与连接串 |

## 快速开始

```bash
# 安装依赖(首次)
npm --prefix server install
npm --prefix app install

# 一键启动(后端 :3001 + 前端 dev server)
npm run dev -- --port 7100

# 生产模式:构建前端后由后端统一托管(单端口)
npm run build
npm start          # http://localhost:3001
```

首次启动会自动建库并灌入种子数据;重置数据删除 `server/data/ocean-heart.db` 后重启即可。

## 功能对照(执行方案 MVP 范围)

- **论坛社区**:9 个版块(新手下海/晒缸/鱼病问诊/生物鉴定/设备/水质/同城/二手置换/商家区),发帖/回帖/点赞/收藏/搜索/精华帖
- **生物资料库**:38 个物种卡(鱼 20 / 珊瑚 12 / 无脊椎 6),难度/性情/最小缸体/食性/兼容性筛选,珊瑚安全与无脊椎安全独立标注,字段级溯源
- **水质速查**:11 参数 × 4 缸型(礁岩/FOWLR/FOT/SPS)对照表
- **设备资料库**:8 大品类 16 个主流型号及选购参数
- **个人中心**:注册登录、后台实名登记、我的帖子、我的收藏
- **to B**:商家入驻申请(营业执照+水生野生动物经营利用许可证)→ 审核 → 认证展示页

## 合规机制(本项目生死线)

1. **跟帖评论后台实名制**:未实名用户发帖/回帖被服务端拦截(403)
2. **保护物种标注**:石珊瑚目/砗磲/海马等 10 个物种标记「国家二级 / CITES 附录Ⅱ + 禁止交易」,资料卡仅作科普展示
3. **二手置换先审后发**:敏感词库命中(砗磲/石珊瑚/鹿角珊瑚/海马/SPS/LPS 等)直接拒绝发布
4. **商家资质核验**:入驻必须提交营业执照,活体类必须附《水生野生动物经营利用许可证》

## 上线前待办(运营侧,方案 4.2 资质路线图)

- ICP 备案(2–4 周)→ 上线后 30 日内公安联网备案
- 开始收费前办 ICP 经营许可证;开通站内交易闭环前办 EDI 证
- 生产环境将数据库切换为 MySQL(替换 Drizzle 驱动),并配置 HTTPS 与域名
